# Spaceport rocket exploration

Doctor Biz asked for a much cooler icon after reviewing the flat emoji tile.
`rocket-dimensional.png` is the resulting design preview: a sculpted ivory
rocket, red fins, warm engine plume and cyan accents on a graphite tile.

Generated with the built-in image generation tool, using the initial flat
rocket icon as the edit target. The PNG is 1254×1254 with
an alpha channel. The output was inspected visually; no native app was built
or tested with this earlier variant. The later nebula variant below is selected.

## Nebula background variant

`rocket-nebula.png` adds violet, indigo and cyan cloud wisps inside the tile,
following Doctor Biz's request for a more nebula-like background. Generated
with the built-in image generation tool from `rocket-dimensional.png`, then
inspected visually. The rocket remains prominent and the outer margins retain
an alpha channel. Doctor Biz approved this variant with “ship it.” It is now
the source for generated app/platform artwork; the earlier dimensional image
remains a design reference. Source selection does not establish a new signed
application build or public release.

### Nebula edit prompt

Use case: precise-object-edit. Edit target: referenced Spaceport rocket app icon. Change ONLY the background INSIDE the rounded-square icon tile to be a bit more nebula-like. Preserve the existing rocket exactly: same ivory ceramic body, red nose and fins, satin metal bands, large cyan-highlighted dark porthole, amber/coral engine flame, position, scale, shape, lighting and sharpness. Preserve the rounded-square tile silhouette, bevel, front-facing framing, transparent outer margins, and the subtle orbital arc and little cyan orbital dot. Replace the plain dark graphite tile surface with a tasteful deep-space nebula: soft wisps of violet, indigo and muted cyan interstellar gas, with a restrained touch of magenta, layered smoky depth and just a few very tiny distant stars. Keep the nebula dark, subtle and lower-contrast than the rocket; it should feel like luminous cosmic clouds embedded under the tile surface, not a busy photographic wallpaper. Rocket remains the unmistakable main subject, clean and highly readable at Dock size. No changes to the spacecraft or flame. No text, no letters, no added objects, no planets, no large starbursts. Preserve actual alpha transparency OUTSIDE the tile. Produce one finished square app icon.

## Original generation prompt

Use case: logo-brand / stylized-concept. Edit target: the referenced Spaceport app icon. Redesign it into a much cooler, distinctive, beautifully crafted macOS app icon, retaining the immediately readable playful 🚀 rocket-emoji idea and the diagonal lower-left to upper-right launch. Produce ONE finished square icon, no presentation board. A chunky sculpted ivory ceramic and satin-aluminum rocket with a vermilion red nose and swept red fins, one large dark circular porthole with a crisp cyan reflected highlight. Rich but restrained 3D depth, precise bevels, broad confident shapes, tactile enamel surfaces, elegant modern space-program industrial design. Strong warm amber-to-coral engine plume as a single bold graphic shape, giving thrust and attitude. Rocket fills roughly 72 percent of a dark midnight graphite rounded-square tile. A subtle oversized orbital arc etched into the tile behind the rocket adds a distinctive spaceport/navigation motif, with one small cyan accent, very low contrast so the rocket dominates. Dramatic upper-left studio key light, controlled edge highlights, deep contact shadow, convincing physical depth without photorealistic clutter. The rocket must look excellent and instantly legible as a 32px Dock icon; bold silhouette, generous separation, no tiny mechanical details. Preserve a perfectly square front-facing icon tile, no perspective tilt to the tile itself. Center the rounded tile on the canvas with transparent outer margins matching the reference approximately 10 percent per edge. Real transparent alpha outside the tile. No words, no letters, no numbers, no labels, no stars, no galaxy wallpaper, no UI, no generic neon glow, no extra objects, no watermark. Overall feeling: an iconic little spacecraft you want to click, premium and adventurous.
