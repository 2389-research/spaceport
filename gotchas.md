# Gotchas

- 2026-11-11: The macOS performance adapter must select its process's fixture window with the same `WINDOW_TITLE` startup uses; a stale product literal prevents all native input measurement after first paint. Use the release-only `performance_gui` sandbox harness for qualification: it clears personal state paths, forwards only the performance budget and reaps its exact child before removing the sandbox. Just and Windows CI select that harness through Cargo so external target directories work. Keep cached/reference selection explicit: the recipe uses presence of `HERDR_PERF_UNCACHED` (even `0`); the cached CI test must not inherit it. Linux lacks native benchmark event delivery and must refuse explicitly rather than report a zero-test pass.

- 2026-11-11: `sheprd_client::APP_NAME` owns Spaceport's product name so typed client diagnostics and the desktop do not diverge; GPUI's window-title constant reads it. The dependency-free `app_name.rs` module supplies the real value to standalone identity and packaging probes; compiling constants alone or parsing a literal window title misses this dependency. Pass the name to Fluent as data to preserve it in pseudo-locales, including setup-relay errors. Setup helper stderr and relay frames are separate display paths; changing the dialog catalog does not rename them. Add Device's local-network refusal must use `Localize` at the display boundary; plain `Display` is English even when the dialog's locale changes.

- 2026-11-11: Keep-awake identity is OS metadata as well as UI copy. Pinned keepawake uses the reason on macOS/Linux and the app name on Linux; derive both from Spaceport's product-name constant. State tests with stand-in guards do not prove that metadata. The opt-in macOS power-assertion test checks only its own PID; RAII releases its real guards even when a check fails.

- 2026-11-11: GitHub's Ubuntu mirror list falls back between Canonical domains, so a Canonical DNS outage can block every Linux job; one independent mirror can also become unreachable. CI uses temporary Ubuntu Deb822 sources with Canonical primary and independent MIT fallback while preserving suites, components and the Ubuntu archive keyring. Plain apt-get update can succeed after failed index downloads: require --error-on=any before installation. Bound metadata attempts to two and install once only after success. Keep developer sources untouched and reject unknown formats; never disable APT signature verification to restore a build.

- 2026-11-10: Preview changelogs start at a published ancestor, not the last Git tag: a failed tag reserves its version without publishing its changes. Before the first release, use the actual fork source in `t00-dependencies.json`, not an earlier candidate source from the plan. Render the explicit range with the shared pinned git-cliff. A same-commit rebuild has empty history; filtered build-only history still renders a version heading under `render_always`.

- 2026-11-10: Doctor Biz's approval to “ship” branding includes rebuilding a usable preview and carrying verification/delivery through. His explicit “push and make it work” also authorizes the necessary GitHub push and signing setup; an uncommitted workflow is not that result. If signing or desktop access blocks the final checks, retain the concrete build and exact failure, and continue independent work while asking for the missing access.

- 2026-11-10: An inherited `RUSTUP_TOOLCHAIN` can override this repository's pinned `rust-toolchain.toml`. Select `RUSTUP_TOOLCHAIN=1.99.0` explicitly for the preview builder when the shell activates another version; do not change dependency requirements to fit the shell.

- 2026-11-09: D62/D63 select the sculpted nebula rocket after Doctor Biz found the first flat emoji too plain. `design/spaceport-icon/rocket-nebula.png` is the approved source; SVG wrappers and raster/platform assets derive from its exact bytes. Preserve Twemoji reference provenance in NOTICE and LICENSE-twemoji. Keep existing internal asset filenames/catalog keys until their packaging and embedded references change together. Regenerate both `.icns` and `.car`: macOS 26 may select the catalog instead of the flattened icon. Development builds use a berry rim; the underlying approved artwork stays unchanged.

- 2026-11-09: Core CLI inspection can have lifecycle side effects: `hc schema` uses the API and can autostart Core, whose launcher restores login HOME even when the query had a private environment. Use the direct-serve test Sandbox with explicit short private socket/XDG paths and exact-child cleanup for runtime probes. A successful schema query is not proof that no process started. For remote chat, missing a chat-named RPC is not the test: an authenticated lossless duplex byte route could suffice, while current `machine.exec` is batch-only.

- 2026-11-09: Teleport module names concealed live chat, pane and process helpers. The remaining migration engine is removed; retained helpers now live in `sheprd-remote::{host_script,agent,snapshot}`. Exact target/session refusal, argument permission choices and output/cancellation limits must survive extraction. Search inferred method calls as well as qualified references: the process viewer still needs `ProcessInfo::foreground_pids`. Desktop chat conversion and reboot recovery were subsequently removed; preserve observation/attachment and explicit runtime launches. T06 still requires verified remote transport and native parity.

- 2026-11-10: D61/D64 approve macOS signed previews as `ai.2389.spaceport` under 2389 Research, Inc (Team `HD9NM9NSMK`), with tag-triggered GitHub prereleases. The tagged commit must belong to main and pass full CI there; local installed-keychain access does not supply CI's P12/password. The protected signing environment needs separate main-branch and `v*` tag deployment rules. This does not enable the inherited public release pipeline; D65 separately selects Sparkle preview updates. Ordinary development builds retain `spaceport.development`; Windows signing is deferred for this task. The legacy `RELEASE_BUILD` flag now belongs to app constants after deleting the unused credential store; its expression and false preview policy stay unchanged. Keep private signing files outside Git and never pass signing secrets into Cargo. Notarization submission is a side effect: persist its UUID and poll it; never retry an uncertain submission blindly. When CI progress is opaque, query authenticated notarytool history/info read-only before inferring an Apple queue delay: the combined step also covers signing, stapling and disk-image creation. An Accepted app submission does not establish that a DMG was submitted or published. Signing scripts must work under macOS Bash 3.2: empty arrays with nounset can exit early, so verify actual output and completion status. Match complete codesign identity fields; substring matches accept ID suffixes. A valid `security find-identity` result does not establish signing access: a locked login keychain can still reject signing. Prefer an isolated temporary import of the supplied matching P12 over changing the login keychain.

- 2026-11-09: D60 authorizes deleting the inherited custom updater, not dropping Spaceport updates. D65 separately selects Sparkle for macOS previews; other platform and package-manager routes, identity and complete update tests remain T12 gates. Preserve the release-build refusal; do not accidentally enable upstream release publishing by deleting its guard.

- 2026-11-10: D65 requires `SURequireSignedFeed` and exact numeric `SUSignedFeedFailureExpirationInterval=0`: Sparkle otherwise allows recovery after 20 days of feed-signature failure. Verify archives before extraction. Sparkle 2.10.1 emits both `will-extract-update` and `did-extract-update` before installer validation: `SPUInstallerDriver` immediately completes launcher setup, and `SPUCoreBasedUpdateDriver` forwards that completion as did-extract. Neither callback proves unarchiving. Archive refusal needs the exact pre-unarchive 4005 → [4005,3002] cause and EdDSA mismatch; validly signed identity/version failures may unarchive to inspect metadata. All negative cases must forbid genuine installation/relaunch events or later-stage install choices. Sparkle trusts its signed publisher to rotate keys and app identity; exact Spaceport ID/Team belong to the release gate, not an invented unconditional installer check. Its SDK root LICENSE is outside Sparkle.framework: pin and bundle it separately. Feature builds need an explicit bundle-relative rpath, and compiled worktree exclusion is independent of preview app identity.

- 2026-11-11: A private HOME does not isolate every macOS store. Foundation NSTemporaryDirectory uses the OS protected per-user temp root despite TMPDIR, while cfprefsd may write the unique fixture bundle-ID domain under the account's Preferences directory despite CFFIXED_USER_HOME. LaunchServices also overwrites HOME despite signed LSEnvironment; the fixture validates its signed private root, then restores its explicit environment with a bounded same-PID exec before running every isolation guard. Sparkle installer helpers independently use NSFileManager URLForDirectory(NSCachesDirectory, NSUserDomainMask), which can choose the account Library/Caches despite the host’s private HOME/search-path guards. Claim absent exact random cache-domain directories0700 in both account and fixture homes before launch; retain owner/device/inode proof. Remove only those same owned claims after hosts/helpers exit, an executable-path census is clear, and scoped exact-tree lsof finds no open files; fail and retain on uncertainty. Never retroactively delete old unclaimed caches, signal recorded helper PIDs, or scan/reset personal domains or cfprefsd. Pin the exact OS temp root/owner and prove preference-domain absence before launch; clean only owned test preference values after process exit.

- 2026-11-10: Rust-cache recursively removes non-Cargo files beneath `target/` on a partial cache hit, including an SDK acquired earlier in the job. Keep the CI Sparkle SDK under `RUNNER_TEMP`, with linker, loader and official-tool tests using that same explicit path. An explicitly configured missing SDK must fail its signing test instead of silently skipping it.

- 2026-11-09: Usage provider names/icons are passive presentation metadata, not evidence of a supported report feed. Keep provider visibility filtering in presentation after removing collectors. Do not restore polling or sign-in readers to populate a missing feed; G-OBS requires a separately verified authoritative source.

- 2026-11-09: Unknown top-level CLI families reject through the launch parser before control-command JSON handling. Even with `--json`, a removed family such as `system` returns exit 2 and text usage on stderr. Valid control commands keep their JSON contract; do not parse an unknown-family rejection as their response schema.

- 2026-11-10: About credits distinguish Spaceport by 2389 Research, Inc., its modifications copyright, and original Sheprd work by Fabien Penso. Preserve both Herdr and Sheprd team credits (D59), the original NOTICE text and Apache-2.0. Spaceport's repository is primary; upstream links stay under credits. The worktree PR banner and Report issue route use the same repository constant; check their expected URLs when that constant changes. Community issue forms, duplicate-search links and the Documentation contact name Spaceport; preserve real Herdr daemon links. The inherited private security-report contact still needs an owner-approved Spaceport route before general production shipping. Fluent placeables include invisible FSI/PDI marks: keep them in rendered/source text, while native glyph inspection skips their ink bounds and compares every visible character. The full sidebar bidi check separately verifies their zero width and lack of missing-glyph boxes.

- 2026-11-09: Doctor Biz wants future task worktrees inside the main checkout's `.worktrees/<task>` directory. The ignore entry prevents nested checkouts from appearing as source changes. Keep active worktrees and delivered test artifacts intact when cleaning old sibling checkouts.

- 2026-11-09: Runtime generation alone is not a deletion criterion. D58 in `docs/spaceport/plan/decisions.json` permits Herdr 1 alongside Core and supersedes D55. Preserve exact runtime ownership and working UX; remove excluded feature routes independently. Core-specific gaps do not establish Herdr 1 parity.

- 2026-11-09: `crates/sheprd-gpui/src/browser` owns shared native tab IDs, split groups, persisted view references, and Herdr terminal navigation after the embedded page engine is removed. Keep that container for Core/Herdr 1 terminal and Devices views; old web/local/blank payloads only decode so the store can discard them while reserving their IDs.

- 2026-11-09: Pseudo-locale leak fixtures record newly shaped text, so consecutive popovers with the same labels can produce no new messages. Test each such surface in its own test. Calling `under_en_xa` twice in one test toggles the thread-local pseudo-locale off on the second call, even with a fresh app context. Use the existing `uncut` helper for truncation measurements; keep whole untranslated labels subject to the leak assertion.
