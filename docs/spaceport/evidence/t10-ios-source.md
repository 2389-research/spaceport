# Native iOS and watch source removal

Bounded RM-PHONE/T10 cut from `e5a192af`. An absence test failed against the native app and workflow before deletion, then passed. The cut removes the Swift app, watch, widgets, shared Swift package, mockups, spikes, simulator tools, XcodeGen project, `.github/workflows/ios.yml`, and all `ios-*` recipes from `justfile`. The desktop icon generator/checker and artwork test no longer read or write iOS catalogs; their desktop branches remain. The historical iOS plans are marked as such, and links to the deleted `ios/README.md` have been updated.

The only files left under `ios/` are 37 JSON fixtures in `ios/SheprdRemoteCore/Tests/SheprdRemoteCoreTests/Fixtures/`. Rust tests in `crates/sheprd-remote-control/src/{apns,auth,native,web}/tests` still read them, including nearby, sealed-alert, presence and v2 reducer vectors. Two Swift-specific fixture README files were removed. The JSON bytes and `.gitattributes` rule were not changed; the fixtures belong to the later phone-server cut. No iOS legal or attribution file was found in the tracked source tree.

Desktop Cargo manifests, Core client, phone server, tag sync, private desktop CLI, release workflow and package scripts were not changed. The desktop release still includes `sheprd-remote-control` and `sheprd-nearby`; RM-PHONE and A30/A54 remain open. T10 stays `not_started` in the task tracker until its prerequisites and full mobile/server removal are met. No real phone, daemon, Core, signing, App Store or user state was used. The Rust phone-server tests and native desktop checks were not run for this source-only cut.

Checks: the new absence test failed twice before deletion (app source and workflow), then passed both cases; the earlier mobile-publication test passed. `just check-artwork` passed four desktop asset tests; `swiftc -frontend -parse` accepted both edited icon scripts. CI policy passed nine tests, desktop release packaging passed 11 tests, and `actionlint`, `just check-file-size`, `just check-sorted`, `python tools/spec.py check --write-report`, and 21 specification-tool tests passed. These checks do not prove the remaining phone server absent or native desktop parity.
