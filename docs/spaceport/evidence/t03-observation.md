# T03 shared Core observation slice

Source: branch based on `d7c8366b06fa21152708f1cadd237f40b4e50179` with the T02 `CoreChanges::next_batch` route. The pinned Core reference remains `cd12ddd88bc11490228343291dc1096c9ed3bf77`.

One app-global `Observation` owns one Core metadata subscription and a worker thread. The worker reads the local `spaceport` document after subscribing and again after a missed batch or a local document notice. It applies terminal changes before replacing one coalesced latest-state slot; UI windows only copy the published projection. A new connection epoch clears terminal and document facts. A lost worker clears its facts and marks them stale; document read/parse errors clear the old value and remain available as typed errors. The per-window `Infos` cache now reads that shared projection, and its former two-second `terminal.list` worker is gone. A just-started terminal survives one fresh snapshot that missed it, but stale observations clear it.
