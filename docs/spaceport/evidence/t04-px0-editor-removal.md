# T04/RM-IDE: retire the px0 embedded editor

This cut follows the [px0 dependency map](t04-px0-editor-dependency.md) at integration `106199bc`. Old `browser-tabs.json` entries with `place: "px0"` still parse, but `Store::with_saved` discards them in memory and reserves their IDs before retaining page and Core tabs. Tests use an in-memory saved file; no personal tab file was read or rewritten. A new tab ID stays above the discarded maximum, so an old group pick cannot acquire unrelated content. The saved-state test was red first: restored IDs `[0, 1, 500]` still included px0; it is green with retained IDs `[0, 1]`, exact Core group identity, page close, and a new ID above 500.

The app no longer installs or polls a px0 launcher, discovers a workbench, opens an embedded editor page, or offers px0 in the group/Terminal menu, command catalog, CLI, control socket, Settings, or config. The private control protocol advances 25→26 and rejects old `tab.px0`/`TabKind::Editor` wire values. Retained tab focus/list/close and exact caller targeting use the existing Store and control paths. Removed the editor-only process cleanup helper and exclusive messages; `icons/code.svg` stays because Orchestrator still uses it. `window/file_links.rs` still opens deliberate local files through the system handler, and rich-chat code copy/rendering remains.
