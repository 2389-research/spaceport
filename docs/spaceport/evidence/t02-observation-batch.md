# T02 subscribed observation batch

`CoreBackend::watch` already opened one unfiltered `events.subscribe` stream, but the `sheprd_backend::Changes` reader exposed only terminal changes. Spaceport now offers `CoreChanges::next_batch` on that same stream. It returns terminal changes, named document invalidations, and a missed-event flag. A missed snapshot clears earlier changes and invalidations in the batch; the observer must refetch watched documents. The existing terminal-only trait path delegates to this method and retains its contract. No second subscription or app transport manager was added.

The focused test first failed to compile because `next_batch` did not exist. Two scripted Core tests now pass: one carries a remote `spaceport` document notice and a terminal title in one batch; the other reports a missed snapshot, drops the older document notice and fences an older event. `cargo +1.99.0 test --locked -p sheprd-core-client --lib` passed 54 active tests with 4 opt-in tests ignored. The private Core `just test-core` run passed all 4 opt-in tests. File-size and sorted checks passed. The app-global observer, document refetch on reconnect and UI projection remain unimplemented, so A53 stays not_run.
