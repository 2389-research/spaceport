# T02 Core document route

Pinned source: herdr-core `cd12ddd88bc11490228343291dc1096c9ed3bf77` (`0.1.18`), `schema/hc.openrpc.json` methods `doc.get` and `doc.set`, and `crates/herdr-core/src/api/types.rs`. Both methods accept an optional saved-machine `on`; `doc.set` compares the supplied version and returns a new version. Core's own remote tests in `crates/herdr-core/tests/docs.rs` cover remote documents and missed notifications. This fork does not infer a workspace RPC from those calls.

The Core client now exposes the observed `on` parameter through typed requests. A scripted-peer test checks exact `on`, name, value and expected version. The existing handshake rejects a Core missing required `doc.set` before any call. The private two-Core fixture writes `spaceport` on `lab`, reads it directly from the remote Core, confirms the local Core's `spaceport` document remains at version zero, then observes a `conflict` refusal for a stale remote write and fetches version two. The fixture uses Core's test-only `HC_SSH` pipe; it does not use real SSH, Tailscale or a personal Core.

The test first failed to compile because the client lacked the machine argument. After implementation, `cargo +1.99.0 test --locked -p sheprd-core-client --lib` passed 44 tests with four ignored live tests. `RUSTUP_TOOLCHAIN=1.99.0 CARGO_TARGET_DIR=/tmp/spaceport-t00-target just test-core /tmp/spaceport-t00-target/debug/herdr-core` passed all four opt-in live tests on macOS. `cargo +1.99.0 check --locked -p sheprd-gpui --bin sheprd -p sheprd-remote-control`, `just check-file-size`, and `git diff --check` passed; Cargo still reported the pre-existing `block` future-compatibility notice. A first test expected an unsupported result for missing `doc.set`; it exposed the stronger existing handshake requirement, and the test now asserts that requirement.

A06/A07/A53 remain **not_run** for Spaceport. This change supplies an exact Core route and CAS refusal only. There is no Spaceport presentation schema, safe rebase, watched-document refresh, or UI projection yet. Native Windows and Linux have not run.
