# T03 workspace document model slice

Source: Spaceport worktree based on `64c7d3706b4717edb02093b3cc4e7a1efc53a209`; pinned Core `cd12ddd88bc11490228343291dc1096c9ed3bf77` (`schema/README.md`, `schema/hc.openrpc.json`). This is a pure presentation model under `core_terminals/workspace_document`. It does not call Core or alter terminal processes or files.

The proposed `spaceport` document schema v1 has ordered `workspaces` with UUID IDs, labels, archive state, optional launch Core identity and members as stable `{core_id,terminal_id}` pairs. The model reads Core's unwritten `null` as an empty v1 document. It rejects newer schemas before editing, duplicate workspace IDs or members, nil UUIDs, invalid Core identities, qualified or unsafe terminal IDs, and bad labels. It stores bounded local Core terminal IDs and Core identities verbatim rather than copying today's ID alphabets. Unknown JSON fields at the document, workspace and member levels survive a rename. Create, rename, archive and delete change only the document value. The caller must supply a fresh UUID and handle Core's version separately.
