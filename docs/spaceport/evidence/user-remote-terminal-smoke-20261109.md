# User-reported remote terminal smoke

On 9 November 2026 Doctor Biz reported that the Spaceport remote connection
was “working great” and that this conversation was being entered through
the connected Herdr session. This follows the earlier report that the app
“connected to everything and it works.”

This supplies hands-on evidence for connection, interactive input and visible
output in Doctor Biz's own setup. No automated fixture or personal-runtime
inspection ran. The exact running executable hash, Herdr generation/version,
and host route were not captured, so this report cannot establish a tested
compatibility range or qualify a particular archived candidate.

Native rich chat, file transfers, service forwarding, notifications, reconnect
identity, process survival after app quit, and other desktop platforms are
outside this report's demonstrated scope. T05 remains in progress; backend,
platform and release acceptance gates remain open. Future isolated tests must
record explicit executable/runtime identity and scenario results.
