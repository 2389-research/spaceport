# Review fixes

- ScrollHandle indexes direct children. Keep live rows direct. Capture snapped extents for departure. Reset form handles on cancel. See [popup evidence](../docs/evidence/review-host-popup-departure.md).
- Headless GPUI exposes element metadata. Qualify accessibility trees natively. Release dependencies disable debug selectors. Run selector GUI suites in debug. See [accessibility evidence](../docs/evidence/review-accessibility-gaps.md).
- GPUI cached paint replays input handlers but omits accessibility nodes. This also holds in pinned `gpui-pre` 0.3.11. Keep terminal geometry, input, and accessibility outside cell-paint caches. Include the full paint theme and font metrics in cache invalidation. Bypass the sidebar cache while accessibility is active. See [native sidebar evidence](../docs/evidence/review-ci-qualification.md#native-bootstrap-results-and-sidebar-retention) and [Core cache boundary](../docs/evidence/review-working-native-profile.md#core-cell-paint-regression-checkpoint).
- zbus encodes fixed arrays as D-Bus structures. Pass slices for arrays. Verify the real wire signature with an isolated peer. See [OS accessibility evidence](../docs/evidence/review-os-accessibility.md).
- APFS rejects invalid UTF-8 filenames with EILSEQ. Preserve OS bytes in Unix APIs. Run real invalid-filename fixtures on Linux. See [CLI transport evidence](../docs/evidence/review-cli-contracts.md).
- A captured Unix process-group number does not preserve identity after reaping. Keep the leader waitable with NOWAIT until group signals finish. Retire signaling before the final reap. See [agent ownership evidence](../docs/evidence/review-jargon-main-integration.md).
- Keep instant headless motion inside GPUI's `cfg(test)` policy. Cargo dev features also reach normal native-test binaries. See [reorder integration evidence](../docs/evidence/review-reorder-integration.md).
- Treat `WouldBlock` as deferred inspection, not invalid ownership, for an accepted batch. Preserve its original deadline and sent phase. Keep poison and queue refusal terminal. See [CI qualification](../docs/evidence/review-ci-qualification.md#close-batch-contention).
- A test glob import from a parent containing gpui::* can import GPUI's test attribute. Import specific dependencies to prevent recursive test expansion.
- A `#[path]` mount changes child-module lookup directories. Declare explicit nested paths and run `just format-check`. Scoped `rustfmt` with `skip_children` can miss broken crate wiring. See [Windows qualification](../docs/evidence/review-squad/windows-native/qualification-plan.md).
- Stage new sources before running `just sort`, `just check-sorted`, and `just check-file-size`. These recipes inspect Git-tracked paths. Untracked files can miss their checks.
- Put application fixture overrides in one `config.local.toml`, including shared and Core settings. A different personal `config.toml` triggers the real loader's migration-conflict refusal. Run file maintenance and startup parsing before launching fixture children. The inherited `view.toml` reader ignores malformed input and reads only selected view keys. See [native error announcements](../docs/evidence/review-native-error-announcements.md) and [profile configuration evidence](../docs/evidence/review-working-native-profile.md#first-mixed-native-evidence-and-configuration-defect).
- Draw a window through `AnyWindowHandle::update`. A typed update borrows the root view, so drawing inside it borrows that view twice. See [status-shape evidence](../docs/evidence/review-status-shapes.md#native-fixture-redraw-correction).
- GPUI simulate_keystrokes sends only KeyDown and may commit text. Send matching KeyUp after a focused frame. Use raw key events for IME ownership. Headless draw does not deliver on_next_frame callbacks. Use simulate_next_frame or sidebar run_frames. See [platform shortcut evidence](../docs/evidence/review-platform-shortcuts.md).
- macOS accepted Unix sockets inherit listener nonblocking mode. Set the peer's required mode explicitly before applying read timeouts. Keep bounded acceptance on the listener. See [CLI peer evidence](../docs/evidence/review-ci-qualification.md#drive-prefixes-and-accepted-cli-streams).
- A Windows verbatim drive prefix needs its root separator before filesystem lookup. Reject remote prefixes before deferring that lookup. See [drive prefix evidence](../docs/evidence/review-ci-qualification.md#drive-prefixes-and-accepted-cli-streams).
- Pinned Herdr TUI automatic tab labels follow position, while IDs and public numbers remain stable. Permit automatic renumbering in accepted batches. Preserve custom-label ownership and exact custom names. See [batch evidence](../docs/evidence/review-popup-close-motion.md#default-tab-labels-after-a-close).
- Avoid value-returning C# fixture methods named `End` or `Process` when calling from Windows PowerShell. Its special binder branch skips boxing, so a Boolean result fails before invocation. Use a domain method name such as `Finish`. See [native image evidence](../docs/evidence/review-image-pane-scroll.md#first-windows-execution-on-97864f275).
- Check Windows fixture pipe readiness without connecting. A connect/drop probe can consume the instance needed by the GUI. Use the no-wait availability check and preserve the fixture's outer deadline. See [startup evidence](../docs/evidence/review-ci-qualification.md#native-startup-and-refusal-consumers-on-b5a55f455).
- Pinned GPUI 0.3.10's Windows atlas inherits a `contains` query that always returns false. Native image proof must combine successful paint submission with actual GPU pixel validation. Keep the headless atlas-entry assertion separate. See [image evidence](../docs/evidence/review-image-pane-scroll.md#native-windows-atlas-query-on-daab7134e).
- Sample authored native images near mapped source texel centers and outside overlays. Pinned DirectX's bilinear atlas filtering mixes source-edge colors. A clipped viewport midpoint can also miss the mapped source center. Require that center's visible containment. See [native samples](../docs/evidence/review-image-pane-scroll.md#native-source-samples-on-23cab5b4b).
- Rich-chat preview runs visual preparation, not normal chat polling. Use the shared conversation-focus and composer constructors for keyboard or accessibility fixtures. Otherwise, the preview can omit the production name, Tab stop, and containment owner. See [fixture parity](../docs/evidence/review-chat-accessibility.md#native-fixture-parity-november-19).
- AccessKit Windows 0.34 maps descriptions to UIA FullDescription and placeholders to HelpText. Empty HelpText does not prove an absent error. Use supported native properties or read-only fixture state. See [clipboard qualification](../docs/evidence/review-clipboard-reads.md#first-native-application-result-on-47fd690d6).
- Private Windows PowerShell helpers must load required system modules explicitly. Reuse the module bootstrap and ProgramFiles forwarding from `accessibility_windows::Running::powershell`. Automatic cmdlet discovery can stall in the cleared sandbox. See [bootstrap evidence](../docs/evidence/review-ci-qualification.md#explicit-system-module-bootstrap).
- Git's MSYS GPG treats native Windows paths as relative POSIX paths. Convert its paths with the sibling `cygpath -u`. Keep native paths for Windows ZIP and upload steps. See [retention evidence](../docs/evidence/review-working-native-profile.md#private-retention-prerequisite).
- Xperf PID/thread filters do not classify stack events as CPU samples. Its HTML stack export drops event identity. Filter verified sampled-profile event names before interpreting CPU shares. Keep all-thread process clocks separate. See [native profile evidence](../docs/evidence/review-working-native-profile.md#first-windows-native-tui-result).
- Build `cmd.exe` paths with native components: `root.join("System32").join("cmd.exe")`. Its parser misreads `System32/cmd.exe`, even when process creation succeeds. The isolated comparison passed all native-path cases and failed all mixed-path cases. See [profile evidence](../docs/evidence/review-working-native-profile.md#sampler-lifecycle-test-checkpoint).
- Managed UIA GetBoundingRectangles returns Rect objects, not COM coordinate scalars. Collapsed ranges may return no rectangles. Check the collapsed caret separately from enclosing-line geometry. See [native terminal qualification](../docs/evidence/review-accessibility-gaps.md#first-native-terminal-result-on-1ad093a96).
- Require parser-owned EOF ranges before reusing Markdown tails. Hidden definitions and excess table cells can match earlier displayed words. Preserve the event's source-space behavior. See [streaming preparation](../docs/evidence/review-streaming-parse-costs.md#validated-streaming-append-preparation).
- Build Core accessibility text after canvas layout, using its current origin and extent. A queued backend resize can leave a wider retained grid. AccessKit does not clip text ranges to their parent. Bound rows, columns, and character geometry before exposing them. See [Core viewport evidence](../docs/evidence/review-accessibility-gaps.md#core-resize-containment-on-3a0bcb00d).
