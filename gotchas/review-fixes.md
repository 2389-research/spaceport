# Review fixes

- ScrollHandle indexes direct children. Keep live rows direct. Capture snapped extents for departure. Reset form handles on cancel. See [popup evidence](../docs/evidence/review-host-popup-departure.md).
- Headless GPUI exposes element metadata. Qualify accessibility trees natively. Release dependencies disable debug selectors. Run selector GUI suites in debug. See [accessibility evidence](../docs/evidence/review-accessibility-gaps.md).
- GPUI 0.3.10 replays cached paint without replaying accessibility nodes. Bypass the sidebar cache while accessibility is active. Preserve ordinary caching. See [native sidebar evidence](../docs/evidence/review-ci-qualification.md#native-bootstrap-results-and-sidebar-retention).
- zbus encodes fixed arrays as D-Bus structures. Pass slices for arrays. Verify the real wire signature with an isolated peer. See [OS accessibility evidence](../docs/evidence/review-os-accessibility.md).
- APFS rejects invalid UTF-8 filenames with EILSEQ. Preserve OS bytes in Unix APIs. Run real invalid-filename fixtures on Linux. See [CLI transport evidence](../docs/evidence/review-cli-contracts.md).
- A captured Unix process-group number does not preserve identity after reaping. Keep the leader waitable with NOWAIT until group signals finish. Retire signaling before the final reap. See [agent ownership evidence](../docs/evidence/review-jargon-main-integration.md).
- Keep instant headless motion inside GPUI's `cfg(test)` policy. Cargo dev features also reach normal native-test binaries. See [reorder integration evidence](../docs/evidence/review-reorder-integration.md).
- Treat `WouldBlock` as deferred inspection, not invalid ownership, for an accepted batch. Preserve its original deadline and sent phase. Keep poison and queue refusal terminal. See [CI qualification](../docs/evidence/review-ci-qualification.md#close-batch-contention).
- A test glob import from a parent containing gpui::* can import GPUI's test attribute. Import specific dependencies to prevent recursive test expansion.
- Put application fixture overrides in `config.local.toml`. The inherited `view.toml` reader ignores malformed input and reads only selected view keys. See [native error announcements](../docs/evidence/review-native-error-announcements.md).
- Draw a window through `AnyWindowHandle::update`. A typed update borrows the root view, so drawing inside it borrows that view twice. See [status-shape evidence](../docs/evidence/review-status-shapes.md#native-fixture-redraw-correction).
- GPUI simulate_keystrokes sends only KeyDown and may commit text. Send matching KeyUp after a focused frame. Use raw key events for IME ownership. Headless draw does not deliver on_next_frame callbacks. Use simulate_next_frame or sidebar run_frames. See [platform shortcut evidence](../docs/evidence/review-platform-shortcuts.md).
- macOS accepted Unix sockets inherit listener nonblocking mode. Set the peer's required mode explicitly before applying read timeouts. Keep bounded acceptance on the listener. See [CLI peer evidence](../docs/evidence/review-ci-qualification.md#drive-prefixes-and-accepted-cli-streams).
- A Windows verbatim drive prefix needs its root separator before filesystem lookup. Reject remote prefixes before deferring that lookup. See [drive prefix evidence](../docs/evidence/review-ci-qualification.md#drive-prefixes-and-accepted-cli-streams).
- Pinned Herdr TUI automatic tab labels follow position, while IDs and public numbers remain stable. Permit automatic renumbering in accepted batches. Preserve custom-label ownership and exact custom names. See [batch evidence](../docs/evidence/review-popup-close-motion.md#default-tab-labels-after-a-close).
- Rich-chat preview runs visual preparation, not normal chat polling. Use the shared conversation-focus and composer constructors for keyboard or accessibility fixtures. Otherwise, the preview can omit the production name, Tab stop, and containment owner. See [fixture parity](../docs/evidence/review-chat-accessibility.md#native-fixture-parity-november-19).
- AccessKit Windows 0.34 maps descriptions to UIA FullDescription and placeholders to HelpText. Empty HelpText does not prove an absent error. Use supported native properties or read-only fixture state. See [clipboard qualification](../docs/evidence/review-clipboard-reads.md#first-native-application-result-on-47fd690d6).
