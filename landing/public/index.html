Every terminal and every agent chat, in one native window.

Native terminals. Spaceport draws every terminal itself in a native window, in the font and theme you pick.

Rich chats. Open a chat with Claude, Codex, Copilot, Gemini, opencode or Pi beside your shells. Flip between the chat view and the terminal under it.

One sidebar. Your workspaces and hosts sit in one list, with an overview of what needs you on each.

Yours to set up. Themes, fonts, shortcuts and language are all settings, in the app or in a file.

Quiet when you want. Notifications and sounds tell you when an agent finishes or asks. Mute a worktree or a whole host.

A command line for agents. The spaceport command drives the running app, so an agent in a pane can use it too.

Who does what

Spaceport is the window. Herdr is the runtime behind it. They are separate projects with separate jobs.

Spaceport

  • Draws your terminals, chats and sidebar
  • Holds your themes, fonts, shortcuts and language
  • Sends notifications and plays sounds
  • Answers the spaceport command
  • Updates itself when you choose Check for Updates

Herdr

  • Runs your terminal processes
  • Keeps your sessions and their state
  • Is installed and updated by you, on its own

Spaceport does not bundle, install, update or migrate Herdr. Read about Herdr at herdr.dev.

How it differs from Sheprd

Spaceport is a fork of Sheprd with a narrower aim: a simpler app, built for agents that run without someone watching. It keeps what that needs and leaves the rest out.

Kept

  • Native terminals
  • Rich agent chats
  • Workspaces
  • Themes, fonts and shortcuts
  • File drops and uploads
  • Port forwarding
  • Notifications
  • Logs and diagnostics
  • A command line for the app

Left out

  • The built-in IDE
  • Git and GitHub tools
  • The embedded browser
  • Cloud provisioning
  • Teleport
  • Agent orchestration
  • Mods
  • The scheduler
  • Phone control

Sheprd is awesome. Everything on the right is there because Sheprd is built for people who work side by side with their agents: reading the code, reviewing the changes, steering as they go. If that is you, get Sheprd. Spaceport is for people who send agents off and check back later.

The cutting is still under way, so a preview can show traces of the right-hand list. Spaceport also ships without a Herdr runtime; you install Herdr yourself.

Get the preview

  1. Install Herdr. Follow the steps at herdr.dev.
  2. Download Spaceport. Open the disk image and drag Spaceport to Applications.
  3. Open it. Later previews arrive through Check for Updates in the app.
